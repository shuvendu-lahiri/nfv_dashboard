Property counts use each PR's latest published report. Fixes are checked model repairs with candidate source patches, not proof of source correctness; unknown fix evidence is shown separately.

Outcome percentages use published properties; fix percentages use all model refutations, including those with unknown fix evidence. Publication rates use attempted PRs. Percentages are rounded to one decimal place; unavailable denominators show N/A. Overall percentages use combined counts, not averages of repository percentages.

AIC averages include all attempts of fully measured PRs. Workflow averages use latest-report runs, exclude the initial queue and include inter-job waits. Coverage is shown beneath each average; missing measurements are excluded, not zero. Overall averages are weighted by their measured PRs or runs.

Counts use the latest published report per PR, not every workflow attempt or previous report. Missing reports remain unknown, not successful zero-finding analyses. Each dashboard includes search, filters, highlighted refutations, original reports and workflow evidence.
